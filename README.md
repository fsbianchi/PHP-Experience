Repositório dedicado ao aprendizado, prática e consolidação dos conceitos fundamentais do PHP. O objetivo deste projeto é construir uma base sólida na linguagem através de exemplos práticos, exercícios e pequenos scripts estruturados.

Conteúdo Abordado:

Sintaxe Básica & Variáveis: Tipos de dados, operadores e manipulação de strings.

Estruturas de Controle: Condicionais (if, else, switch) e laços de repetição (for, while, foreach).

Funções: Criação, escopo, parâmetros e retorno de valores.

Arrays: Manipulação, iteração e funções nativas de arrays.
